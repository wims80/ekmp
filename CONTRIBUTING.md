# Contributing

Bug reports and pull requests are welcome. Please open an issue first for
changes that alter user-visible posting, authentication, storage, or release
behavior.

The maintainer retains sole write access and reviews contributions on a
best-effort basis. Do not include credentials, refresh tokens, local
configuration, or other sensitive data in issues, pull requests, commits, or
test fixtures.

By submitting a pull request, you agree that your contribution may be
distributed under the repository's MIT license.
