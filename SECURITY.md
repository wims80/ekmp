# Security policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for security
issues. Do not open a public issue containing refresh tokens, `ekmp.json`,
authorization codes, EVE character data that should remain private, or
killmail hashes.

If private reporting is unavailable, contact the repository owner privately
through GitHub and include only the minimum information needed to establish
contact. Do not send credentials.

## Supported releases

Only the newest published release is supported. Security fixes are released as
a new version; published binary assets are not silently replaced.
